📖 Come usare AG Rekordbox Mix Optimizer su qualsiasi PC

  1. 1. Esporta le tue Playlist da Rekordbox:
    Apri Rekordbox sul tuo PC/Mac e clicca in alto su File → Esporta collezione in formato xml (oppure clicca col tasto destro su una playlist e scegli Esporta una playlist → .m3u8).
  2. 2. Carica il file in questa Web App (GitHub Pages):
    Clicca su 📂 Carica rekordbox.xml / .m3u8 (o trascina il file nella barra in alto). Vedrai comparire a sinistra tutte le tue cartelle e playlist di Rekordbox.
  3. 3. (Opzionale) Analisi Audio DSP Reale sui file del PC:
    Se vuoi che DJSet_Analyzer analizzi anche lo spettro audio reale (Sub-Bass, Kick, Groove, Energia RMS) dei file presenti sul PC oltre ai dati di Rekordbox, clicca su 🎧 Collega Cartella Audio PC e seleziona la cartella dove tieni i tuoi MP3/WAV/AIFF. L'analisi avviene al 100% nella RAM del browser senza caricare alcun file su internet.
  4. 4. Crea il Mix Perfetto:
    Scegli la playlist a sinistra e premi ⚡ Ottimizza Ordine Brani (Mix Perfetto). L'algoritmo calcola l'affinità col tuo DNA Acustico AlexGherra e applica il sequenziatore Camelot Wheel + 2-Opt.
  5. 5. Riporta la Playlist ordinata dentro Rekordbox:
    • Metodo Rapido (1 secondo): Premi 📀 Scarica Playlist .m3u8 e trascina il file scaricato direttamente nella colonna Playlist di Rekordbox. Rekordbox riconoscerà subito i tuoi brani mantenendo tutti i tuoi Cue Point, Hot Cue e Beatgrid!
    • Metodo XML Completo: Premi 💾 Scarica rekordbox.xml Aggiornato. In Rekordbox vai in Preferenze → Avanzate → Database → Libreria rekordbox xml, seleziona il file scaricato e nella vista albero a sinistra importa la playlist aggiornata con tasto destro → Importa in Collezione.
